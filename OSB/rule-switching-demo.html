Crossing rules or narrow-channel rule?

Illustrative autonomous navigation system (ANS) logic for the Ever Smart holdings, run on the paper’s five verification scenarios. Own ship is outbound in the channel.

Verification run: all five scenarios
Placeholder parameters (Appendix A)

Not a standard and not validated by any Administration, class society or the Court. Thresholds are placeholders to be set by vessel-specific verification. The sensor model is simulated noise, not measured data. The logic is an engineering reading of Evergreen Marine v Nautical Challenge [2021] UKSC 6, which supplies the legal test but no numbers.

Companion to the MASS Regulatory Bridge working paper (13 November 2026, corrected 14 November 2026), section 4.4 and Appendix A. Limits: (1) the paper’s 5-minute station-keeping duration and heading-oscillation test are not implemented; the simulation uses an instantaneous speed gate; (2) the rows of Appendix A marked “simulation” are the values used here; (3) results depend on the random seed: on the fixed seeds all five scenarios pass, but in a 40-seed check one run of scenario 2 never left the crossing state, a missed detection under sensor noise; (4) withholding Rule 17 action in the degraded state, which this page does not do, causes a collision in scenario 5.
