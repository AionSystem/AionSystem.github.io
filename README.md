## What This Repository Is

This is the source for the **AionSystem GitHub Pages site** — the public face of the **Sovereign Architect** brand and the gateway to 300+ AI reliability frameworks.  
It serves as:

- A commercial **Vault** where visitors can browse and purchase Docker‑sealed frameworks
- A **pipeline explainer** that demos how ideas become locked, deployable machines
- A portal for the **AI Reliability Snapshot** audit service
- A technical **showroom** for open‑source tools and live simulations
- The **home of the hyperdiamond identity** — the crystalline lattice that others build upon

## Development

All pages are static HTML/CSS/JS. The shared assets (`/assets/css/aion-core.css`, `/assets/js/main.js`) provide a consistent look and behaviour across the site.

To run locally, simply clone the repository and open `index.html` in a browser — no build step required.

**Contribution** is currently limited to the open‑source frameworks. For collaboration on the Vault or private repos, see the contact page.
